BUILD FOCUS WITHOUT ANDROID STUDIO
==================================
1. Download and extract this ZIP.
2. Open https://github.com/Sumanthakur8/FOCUS (or your repository).
3. Upload the CONTENTS of this folder to the repository root. Merge folders; do not upload the outer FOCUS-Complete-Project folder itself.
4. Make sure .github/workflows/build-apk.yml is included. If GitHub's web uploader hides dot folders, create the workflow file on GitHub manually using the included file as a guide.
5. Commit changes.
6. Go to Actions > Build FOCUS APK. If it hasn't started automatically, choose Run workflow.
7. When successful, open the run and download the FOCUS-debug-apk artifact.
8. Extract the artifact ZIP; install app-debug.apk on your Android device.

The APK has not been compiled or tested here. If the workflow fails, share the error log.
